# 🇮🇳 JanConnect – AI-Powered Citizen Grievance Navigator

> **Turning citizen voices into actionable public-service complaints.**

JanConnect is a multilingual, AI-powered citizen grievance platform designed to simplify the process of reporting and tracking public-service problems.

Citizens often know the problem they are facing, but they may not know **which department to contact, what information is required, how to write a formal complaint, where to submit it, or how to track its progress**.

JanConnect bridges this gap by allowing citizens to explain their problem naturally through **voice or text** and guiding them through an intelligent grievance workflow.

---

# 🌟 Why JanConnect?

Traditional grievance systems can be difficult for citizens because they may involve:

- Complex forms
- Department confusion
- Technical terminology
- Language barriers
- Limited digital literacy
- Lack of guidance
- Difficulty tracking complaints

JanConnect changes this experience from:

```text
"I have a problem, but I don't know where or how to complain."
```

to:

```text
"I can describe my problem naturally,
and JanConnect helps me turn it into an actionable complaint."
```

# 28. 🔒 Environment-Based Configuration

Sensitive configuration should be supplied using environment variables rather than hard-coded credentials.

Example:

```properties
spring.application.name=JanConnect

# SERVER
server.port=${PORT:8081}

# DATABASE
spring.datasource.url=${DB_URL:jdbc:mysql://localhost:3306/janconnect?createDatabaseIfNotExist=true&useSSL=false&allowPublicKeyRetrieval=true&serverTimezone=Asia/Kolkata}
spring.datasource.username=${DB_USERNAME:root}
spring.datasource.password=${DB_PASSWORD}
spring.datasource.driver-class-name=com.mysql.cj.jdbc.Driver

# JPA / HIBERNATE
spring.jpa.hibernate.ddl-auto=update
spring.jpa.show-sql=false
spring.jpa.open-in-view=false
spring.jpa.properties.hibernate.dialect=org.hibernate.dialect.MySQLDialect
spring.jpa.properties.hibernate.format_sql=true

# JWT
jwt.secret=${JWT_SECRET}
jwt.expiration=86400000

# FILE UPLOAD
spring.servlet.multipart.max-file-size=10MB
spring.servlet.multipart.max-request-size=10MB
file.upload-dir=${FILE_UPLOAD_DIR:uploads}

# AI
ai.api.key=${AI_API_KEY:}

# ACTUATOR
management.endpoints.web.exposure.include=health
management.endpoint.health.show-details=never

# LOGGING
logging.level.com.janconnect=INFO
logging.level.org.springframework.security=WARN
```

Important environment variables:

```text
PORT
DB_URL
DB_USERNAME
DB_PASSWORD
JWT_SECRET
AI_API_KEY
```

> **Security Note:** Database passwords, JWT secrets, AI API keys, and other credentials should never be committed to GitHub.

# 💡 Innovation

JanConnect is not designed as only a chatbot.

Its key innovation is the **end-to-end grievance workflow**:

```text
Understand
    ↓
Classify
    ↓
Route
    ↓
Generate
    ↓
Confirm
    ↓
Submit
    ↓
Track
```

Instead of simply answering:

```text
"What department handles this?"
```

JanConnect is designed to guide the citizen through:

```text
Problem
   ↓
Understanding
   ↓
Structured Complaint
   ↓
Department
   ↓
Submission
   ↓
Tracking
```
